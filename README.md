# 🚀 Rocketseat Discover

## 💻 Sobre o projeto

O **Discover** é um agregador de links para ser usado como uma "bio" em redes sociais. O projeto foi desenvolvido durante o curso **Discover** da Rocketseat, servindo como uma introdução prática ao desenvolvimento web moderno.

O objetivo principal foi criar uma página adaptável (responsiva) que permite ao usuário alternar entre os modos **claro (light)** e **escuro (dark)** com apenas um clique.

---

## 🛠️ Tecnologias

Este projeto foi construído utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização com o uso de variáveis, Flexbox e Media Queries para responsividade.
- **JavaScript**: Lógica de manipulação do DOM (Document Object Model) para troca de temas.
- **Git/GitHub**: Controle de versão e hospedagem da aplicação.

---

## ✨ Funcionalidades

- [x] **Dark/Light Mode**: Alternância de cores de fundo e textos.
- [x] **Troca de Avatar**: A imagem de perfil muda automaticamente conforme o tema selecionado.
- [x] **Responsividade**: Layout otimizado para Mobile e Desktop.
- [x] **Efeitos de Hover**: Interatividade visual nos botões de links.
